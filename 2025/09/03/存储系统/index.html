存储器的分类?

  1. 按在计算机中的作用（层次）分类

    1. 主存储器，主存，内存储器（内存）
    2. 辅助存储器，辅存，外存储器（外存）
    3. 高速缓冲存储器，Cache

  2. 按照存储介质分类

    • 按存储介质，存储器可分为磁表面存储器（磁盘、磁带）、磁芯存储器、半导体存储器（MOS型存储器、双极型存储器）和光存储器（光盘）

  3. 按存取方式分类

    1. 随机存储器（RAM）分动态RAM和静态RAM
    2. 只读存储器（ROM）
    3. 串行访问存储器，包括顺序存储器（磁带）和直接存取存储器（磁盘，光盘）

  4. 按信息的可保存性分类

    • 易失性存取（RAM）和 非易失性存储器（ROM）以及破坏性和非破坏性读出

存储器的性能指标？

  • 存储器有三个主要的性能指标，存储容量，单位成本，存储速度。

主存储器和CPU之间的连接
好的，我们来详细解释计算机组成原理中的**位扩展（位扩展）和字扩展（字扩展）**这两个核心概念。它们都是在设计存储器系统（尤其是主存）时，为了满足特定容量或数据宽度需求，使用多个较小容量的存储芯片（如RAM芯片）进行组合连接的方法。

核心目标： 用多片小容量、窄数据位宽的存储芯片，构建一个大容量、宽数据位宽的存储器系统。

1. 位扩展 (Bit Extension / Bit-Wise Extension)

  • 目标：增加存储器的数据位宽（字长）。
  • 问题： 现有存储芯片的数据位宽（比如每个地址单元输出的数据位数）小于所需的总数据位宽。
  • 解决方案： 将多片芯片并联，共享相同的地址线和控制线，每片芯片负责提供最终数据字的一部分（一位或几位）。
  • 关键点：
    • 地址空间不变： 并联的所有芯片都响应相同的地址范围。访问一个地址时，所有芯片同时被选中。
    • 数据位宽增加： 每片芯片提供一部分数据位，它们的数据输出线共同组成更宽的数据总线。
    • 控制信号共享： 所有芯片的片选(CS)、读(RD/OE)、写(WR/WE)等控制信号连接在一起，确保它们同时被使能并执行相同的操作（读或写）。
    • 地址线共享： 所有芯片的地址输入引脚(A0-An)直接连接在一起，并连接到系统地址总线的相应低位。
  • 如何工作：
    • 读操作： CPU发出一个地址和读命令。所有并联芯片同时被选中，各自输出其对应地址单元存储的数据位（例如，芯片1输出D0-D3，芯片2输出D4-D7）。这些输出组合起来形成完整的、位宽更宽的数据字（例如D0-D7），送到CPU。
    • 写操作： CPU发出地址、写命令和完整的数据字（例如D0-D7）。所有并联芯片同时被选中。数据总线的不同部分被分别送到不同芯片的数据输入引脚（例如，D0-D3送到芯片1的DI0-DI3，D4-D7送到芯片2的DI0-DI3），并写入各自芯片的相同地址单元。
  • 结果： 存储器的地址单元数量不变（仍等于单个芯片的容量），但每个地址单元存储的数据位数（字长）增加了。
  • 公式： 总存储容量 = 单个芯片容量 × 芯片数量 (容量单位是存储单元数量，不是总位数)
    总数据位宽 = 单个芯片数据位宽 × 芯片数量
  • 实例： 用4片 1K × 4位 的存储芯片，通过位扩展组成一个 1K × 16位 的存储器。
    • 每片芯片有10根地址线 (A0-A9，因为 2^10 = 1K)，4根数据线(I/O0-I/O3)。
    • 连接：
      • 所有芯片的 A0-A9 并联，接系统地址总线 A0-A9。
      • 所有芯片的 CS (片选), RD (读), WR (写) 并联，接系统控制总线。
      • 芯片1的 I/O0-I/O3 接系统数据总线 D0-D3。
      • 芯片2的 I/O0-I/O3 接系统数据总线 D4-D7。
      • 芯片3的 I/O0-I/O3 接系统数据总线 D8-D11。
      • 芯片4的 I/O0-I/O3 接系统数据总线 D12-D15。
    • 效果： 访问地址 0x000 时，4片芯片同时输出/输入各自4位，系统数据总线上得到/写入完整的16位数据。

2. 字扩展 (Word Extension / Word-Wise Extension)

  • 目标：增加存储器的地址空间（存储单元数量）。
  • 问题： 现有存储芯片的地址空间（容量）小于所需的总地址空间。
  • 解决方案： 将多片芯片的地址空间首尾相连，每片芯片占据总地址空间的一个连续区间（块）。需要一个地址译码器根据地址总线的高位部分产生不同的片选信号(CS)，在某个时刻只选中一片（或一组）芯片。
  • 关键点：
    • 数据位宽不变： 所有芯片的数据位宽必须相同，并且等于系统所需的数据位宽。它们的数据线并联在一起，接到系统数据总线上（需要三态输出控制，避免冲突）。
    • 地址空间增加： 每片芯片负责总地址空间的一部分（一个地址块）。
    • 片选是关键： 地址总线的高位部分(A[n+m-1] - A[n])送入地址译码器，译码器输出不同的片选信号(CS0, CS1, …)连接到各个芯片的片选引脚。地址总线的低位部分(A[n-1] - A0)直接连接到所有芯片的地址引脚，用于选择芯片内部的存储单元。
    • 控制信号共享： 所有芯片的读(RD/OE)、写(WR/WE)控制信号通常并联在一起，接系统控制总线。
  • 如何工作：
    • 地址分配： CPU发出的地址被分成两部分：
      • 高位地址 (A[n+m-1] - A[n])：送入地址译码器，决定哪一片（或哪一组）芯片被选中（激活其CS）。
      • 低位地址 (A[n-1] - A0)：连接到所有芯片的地址输入引脚，用于选中被激活芯片内部的某个具体单元。
    • 读/写操作： 当CPU发出地址和命令时：
      1. 地址译码器根据高位地址激活对应芯片的CS信号（只有一片芯片被选中）。
      2. 被选中的芯片根据低位地址访问其内部的存储单元。
      3. 如果是读操作，被选中芯片将其单元内容输出到数据总线上（其他芯片因CS无效而处于高阻态）。
      4. 如果是写操作，数据总线上的数据被写入被选中芯片的指定单元。
  • 结果： 存储器的数据位宽不变，但地址单元数量（容量）增加了。
  • 公式： 总存储容量 = 单个芯片容量 × 芯片数量
    总数据位宽 = 单个芯片数据位宽 (保持不变)
  • 实例： 用4片 2K × 8位 的存储芯片，通过字扩展组成一个 8K × 8位 的存储器。
    • 每片芯片有11根地址线(A0-A10，因为 2^11 = 2K)，8根数据线(D0-D7)。
    • 系统需要13根地址线(A0-A12，因为 2^13 = 8K)，8根数据线(D0-D7)。
    • 连接：
      • 所有芯片的 A0-A10 并联，接系统地址总线 A0-A10 (低位地址)。
      • 所有芯片的 D0-D7 并联，接系统数据总线 D0-D7。
      • 所有芯片的 RD (读), WR (写) 并联，接系统控制总线。
      • 系统地址总线的高2位 A12, A11 送入一个 2-4线译码器。
      • 译码器输出 Y0, Y1, Y2, Y3 分别连接到芯片1, 芯片2, 芯片3, 芯片4的片选引脚 CS。
    • 地址分配：
      • A12 A11 = 00 -> Y0=0 (有效) -> 选中芯片1 (地址范围 0x0000 - 0x07FF)
      • A12 A11 = 01 -> Y1=0 -> 选中芯片2 (地址范围 0x0800 - 0x0FFF)
      • A12 A11 = 10 -> Y2=0 -> 选中芯片3 (地址范围 0x1000 - 0x17FF)
      • A12 A11 = 11 -> Y3=0 -> 选中芯片4 (地址范围 0x1800 - 0x1FFF)
    • 效果： 访问地址 0x0000 时，只有芯片1被选中；访问地址 0x0A00 时，只有芯片2被选中（A12A11=01，A10-A0=0x200）。每次访问只有一片芯片在工作，提供8位数据。

总结对比表

特性 位扩展 (Bit Extension) 字扩展 (Word Extension)
主要目的 增加数据位宽 (字长) 增加地址空间 (容量)
芯片连接 并联 (共享地址/控制线) 地址块串联 (共享数据/部分地址/控制线)
地址空间 不变 (所有芯片响应相同地址范围) 增加 (每片芯片响应不同地址块)
数据位宽 增加 (每片芯片提供部分数据位) 不变 (所有芯片提供相同位宽数据)
关键信号 共享地址线、共享控制线 共享数据线、共享低位地址线、共享控制线、片选(CS)
核心器件 不需要额外器件 地址译码器 (产生片选信号)
操作特点 访问一个地址，所有芯片同时工作 访问一个地址，只有一片芯片工作
结果容量 总容量 = 单芯片容量 (单元数) 总容量 = 单芯片容量 × 芯片数
结果位宽 总位宽 = 单芯片位宽 × 芯片数 总位宽 = 单芯片位宽
典型应用 组成所需数据总线宽度 (如16位、32位、64位) 扩展存储容量 (如从64KB扩展到256KB)

实际应用

在实际的计算机系统中，位扩展和字扩展通常是同时使用的，以满足大容量和宽数据总线的需求。例如：

  1. 内存条(DIMM)： 一条标准DDR4内存条通常是64位宽。这通常由8颗（或9颗，含ECC）位宽为8位的DRAM芯片通过位扩展实现（8位 x 8颗 = 64位）。同时，内存条上的多颗芯片也通过内部或外部逻辑进行字扩展，以提供更大的总容量（如单条8GB、16GB）。
  2. 设计一个32位宽、4MB的存储器：
    • 可能需要使用多片 1M x 4位 的芯片。
    • 首先进行位扩展：用8片芯片组成一组，提供32位宽（4位 x 8片 = 32位），但容量只有1M x 32位 = 4MB？不对，1M单元 x 32位/单元 = 32Mb = 4MB。等等，1M单元是地址单元数量，32位是每个单元的数据量，所以总容量是 1M * 32位 = 32兆位(Mb) = 4兆字节(MB)。但这只有4MB容量，而目标是4MB？ 这里有点混淆。重新设计：
    • 目标：4MB = 4,194,304 字节 = 1,048,576 个32位字 (因为4字节/字)。
    • 芯片选择：假设有 512K x 8位 的芯片。
    • 位扩展：用4片芯片组成一组，提供32位宽（8位 x 4片 = 32位）。这组芯片的容量是512K x 32位 = 2MB (512K单元 * 4字节/单元 = 2,097,152字节 = 2MB)。
    • 字扩展：需要两组这样的芯片（共8片），用地址译码器控制片选。这样总容量就是 2组 x 2MB = 4MB。

理解位扩展和字扩展是理解计算机如何组织主存储器以及CPU如何与内存交互的基础。

磁盘存储器

一、磁表面存储器原理

  1. 读写原理
    • 磁表面存储器（磁带/机械硬盘）通过电磁铁磁化磁性涂层记录数据
    • 写操作：线圈电流方向 → 磁极方向 → 二进制状态（例：左S右N=0，左N右S=1）
    • 读操作：磁带移动切割磁感线 → 线圈感应电流方向 → 识别0/1
  2. 核心特性
    • 串行读写：每次只能读写1比特
    • 不可并行：读写操作不能同时进行
    • 需转换电路：主机并行数据 ↔ 磁盘串行数据（串并转换电路）

二、磁盘组成结构

1. 物理结构

组件 功能说明
盘片 表面涂磁性材料，多个盘片叠放
磁头 每盘面对应1个读写磁头（磁头数=记录面数）
磁道 盘面上的同心圆轨道
柱面 不同盘面相同半径的磁道集合
扇区 磁道的扇形分段，读写最小单位（通常512B-4KB）

2. 机械部件

  • 磁盘驱动器：机械部分（马达驱动盘片旋转，磁头臂移动）
  • 磁盘控制器：电子部分（实现与主机的数据交换，支持SATA/IDE等标准）

三、磁盘性能指标

1. 容量

  • 非格式化容量：物理最大比特存储量
  • 格式化容量：实际可用容量（需预留备用扇区），格式化 < 非格式化

2. 记录密度

类型 定义 计算公式
道密度 半径方向单位长度磁道数 总磁道数 = 道密度 × 半径长度
位密度 单磁道单位长度比特数 注：内圈位密度 > 外圈位密度
面密度 单位面积存储量 面密度 = 道密度 × 位密度

3. 平均存取时间（重点！）

$$T_{access} = T_{seek} + T_{rotation} + T_{transmit}$$

  • 寻道时间 $T_{seek}$：移动磁头到目标磁道的时间（题目通常直接给出平均值）
  • 旋转延迟 $T_{rotation}$：目标扇区转到磁头下方的时间
    $$T_{rotation} = \frac{1}{2} \times \frac{60}{RPM} \text{ (秒)} \quad \text{(RPM=磁盘转速)}$$
  • 传输时间 $T_{transmit}$：扇区数据读写时间
    $$T_{transmit} = \frac{1}{RPM} \times \frac{60}{N_{sector}} \text{ (秒)} \quad \text{($N_{sector}$=每磁道扇区数)}$$

4. 数据传输率

  • 理论最大值：$DataRate = RPM \times BytesPerTrack$
    （例：7200RPM，每磁道80KB → $\frac{7200}{60} \times 80KB = 9.6MB/s$）

四、磁盘地址结构

地址格式：驱动器号 | 柱面号(磁道) | 盘面号(磁头) | 扇区号

  • 驱动器号：选择物理磁盘（多磁盘系统）
  • 柱面号：确定磁道位置（移动磁头臂）
  • 盘面号：激活对应磁头
  • 扇区号：定位具体读写位置

📌 真题注意：给定磁盘参数时，需计算地址总位数（例：4驱动器+256柱面+16盘面+16扇区 → $2+8+4+4=18$位）

五、磁盘冗余阵列（RAID）

RAID方案对比

级别 核心机制 优点 缺点 容错能力
RAID 0 数据条带化分布 读写速度最快 无冗余 ❌ 无容错
RAID 1 磁盘镜像 高可靠性，可校验错误 存储利用率50% ✔️ 支持容错
RAID 2 位级分散+海明校验 冗余比例低（例：4数据位+3校验位） 实现复杂 ✔️ 纠1位错/检2位错
RAID 5 块级分散+分布式校验 兼顾速度与可靠性 校验计算开销 ✔️ 最优商用方案

核心考点

  1. RAID 0：提升速度但无容错能力（磁盘损坏导致数据永久丢失）
  2. RAID 1：镜像备份，可靠性高但存储利用率仅50%
  3. 趋势：RAID级别↑ → 冗余占比↓ → 成本↓ & 可靠性↑

六、易错点总结

  1. 位密度特性：内圈磁道位密度 > 外圈磁道（相同扇区容量下）
  2. 读写限制：串行操作，不可同时读写
  3. RAID 0误区：虽提升速度，但不提供数据安全性
  4. 旋转延迟计算：默认取磁盘转半圈时间（$ \frac{1}{2RPM} $）
  5. 格式化容量：实际可用空间小于物理容量（需扣除管理扇区）
